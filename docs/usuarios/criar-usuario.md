# Como criar um novo usuário no VERGROUP

Este documento explica o fluxo atual para cadastrar pessoas no sistema interno.

## Onde fica

1. Acesse **Administração & Governança**.
2. Clique em **+ Convidar Colaborador**.
3. Na janela de convite, use a aba que melhor atende o caso:
   - **Por Link Seguro**: gera um link para a pessoa se cadastrar.
   - **Por E-mail / Em Massa**: envia convite por e-mail.
   - **Criar Diretamente**: cria o usuário interno já no sistema.
   - **Parceiro Externo**: acesso restrito para terceiros.

## Fluxo recomendado para criar um usuário interno

Use a aba **Criar Diretamente**.

### Passo a passo

1. Preencha o **nome** da pessoa.
2. Preencha o **e-mail**.
3. Escolha a **empresa**.
4. Escolha o **departamento** se já existir uma estrutura definida.
5. Escolha a **equipe** se for necessário.
6. Defina o **papel** do usuário.
7. Informe o **cargo** se desejar. Esse campo é opcional.
8. Escolha se o sistema deve **enviar o convite imediatamente**.
9. Salve.

## O que acontece no sistema

Quando você salva um usuário pela aba **Criar Diretamente**:

- o sistema cria o registro do usuário;
- associa empresa, departamento e equipe, quando informados;
- define o papel do usuário;
- registra o usuário como:
  - **ativo**, se o envio imediato estiver ligado;
  - **convidado**, se o envio imediato estiver desligado;
- se o envio imediato estiver desligado, o sistema também cria um convite pendente com status de envio não realizado.

## Quando usar convite por link ou e-mail

Se a pessoa ainda não deve ser criada diretamente no sistema, use uma destas opções:

- **Por Link Seguro**: melhor para onboarding simples;
- **Por E-mail / Em Massa**: melhor quando você já tem a lista de pessoas;
- **Parceiro Externo**: melhor para acesso temporário e controlado.

## Campos obrigatórios e opcionais

### Obrigatórios
- Nome
- E-mail
- Empresa
- Papel

### Opcionais
- Departamento
- Equipe
- Cargo
- Gestor direto

## Observações importantes

- O sistema guarda as alterações e convites com rastreabilidade.
- O papel e as permissões podem ser ajustados depois, na edição do usuário.
- Para usuários internos, o fluxo mais rápido é sempre a aba **Criar Diretamente**.

## Resumo rápido

Para criar um novo usuário:

**Administração & Governança → + Convidar Colaborador → Criar Diretamente → preencher dados → salvar**
